## What we have to offer

Welcome to .prtgn! A CLI based file format for Protogens. Powered by Rust and [![Built With Ratatui](https://img.shields.io/badge/Built_With_Ratatui-000?logo=ratatui&logoColor=fff)](https://ratatui.rs/)!

We offer 'secure' files only select programs have the ability to understand. Take a look through some text files, listen to some music, or even gaze uppon the all mighty fox image selector that is fox.pics. All right from your built in CLI interface. Works with x86_64 and Aarch64 processors!

Along with that we have a wonderful built-in translation for Human or other species to understand. Look at us doing the diversity and inclucivity. 

Have a look at our wonderful command structure! Start out with 'prtgn' and then apply any of the sub commands avalible! Check them out useing 'prtgn -h'

**Debian (deb) install package :** [Cargo-deb](https://crates.io/crates/cargo-deb)

  INNO Registry PATH : `Root: HKCU; Subkey: "Environment"; ValueType: expandsz; ValueName: "Path"; ValueData: "{olddata};{app}"`
